# Asset specification

All current art is a **temporary placeholder** generated by `Tools/gen_sprites.py`. It is not production art.
Final art must keep the **same file names and canvas sizes**, so you can swap the files without changing any code.
After real art lands, stop running `gen_sprites.py`, because it would overwrite your files.

## Resolution

The scene is drawn at **1 art pixel = 1 iPhone point** (3 screen pixels on most iPhones; iPad will use 2 points per pixel).
The cat is 64×64 and the room core is 360×400, which matches the detail level of the reference mockups.

## Global rules

- PNG, RGBA, transparent background, exact canvas size below. Only "1x" PNGs; the game scales them by whole numbers.
- **Hard pixel edges only**: no anti-aliasing, no blur, no soft shadows, no gradients that aren't dithered by hand.
- One outline color for characters: dark brown `#3B2628`, 1 px.
- Limited palette: around 24–32 colors for the whole game; the cat uses about 8 of them.
- Light comes from the top left: shading on the lower right, highlight on the upper left.
- Original art only.

## AI workflow and cleanup checklist (for each sprite)

AI image tools don't produce real pixel grids. Each image needs these steps:

1. **Generate** at large size with a fixed style prompt, for example: *"32-bit pixel art, cute orange and white kitten,
   front view sitting, big eyes, 1px dark brown outline, soft pastel palette, flat transparent background, game sprite"*.
   Use the same prompt and seed or reference image for every frame.
2. **Downscale to the target grid** with nearest-neighbor (Aseprite: Sprite → Sprite Size, or Pixelorama).
   A 1024 px image for a 64×64 sprite = 16:1, so it shrinks cleanly.
3. **Reduce the palette** to the shared palette (Aseprite: Sprite → Color Mode → Indexed, using the palette file).
4. **Clean up by hand**: remove stray pixels, close the outline, make the eyes symmetric, fix single-pixel noise.
5. **Animations**: make the frames from the cleaned idle frame by editing it, not by generating new AI images.
   Otherwise the size and face drift between frames.
6. **Align**: feet on the bottom row, body centered at x = 32 in every frame. Check with onion skin.
7. **Export** with the exact name below, drop it into the matching `.imageset` folder, and replace the PNG.
