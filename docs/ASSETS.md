# Asset specification

All current art is a **temporary placeholder** generated by `Tools/gen_sprites.py`. It is not production art.
Final art must keep the same asset names, so you can swap the files without changing any code.

## Global rules

- PNG, RGBA, 1x only (the game scales by whole numbers with nearest-neighbor filtering). No anti-aliased edges.
- One art pixel = one PNG pixel. Same pixel density everywhere.
- Palette: soft pastels, warm light, dark-brown outline `#3B2628`.
- Original art only.
